Un logiciel simple pour rechercher ses fichiers sur Windows

Retrio recherche vos PDF, documents et photos sur Windows à partir de leur contenu, même lorsque leur nom est incompréhensible.

Une recherche pensée pour les utilisateurs

Retrio guide l’utilisateur en quatre étapes : choisir les dossiers, lancer l’analyse, consulter les statistiques puis décrire le fichier recherché avec ses propres mots.

Documents et photos au même endroit

Le logiciel analyse les PDF, les documents bureautiques et les images compatibles. Les filtres permettent de limiter les résultats à un type ou un dossier.

Une meilleure correspondance visible

Le résultat le plus pertinent apparaît en premier avec un encadrement distinct. Son aperçu, son emplacement et les actions pour l’ouvrir restent accessibles.

Un fonctionnement local

Retrio n’utilise pas vos fichiers pour entraîner un service distant. L’analyse et la recherche s’exécutent sur votre PC, après l’installation.

Questions fréquentes

Sur quelles versions de Windows fonctionne Retrio ?

La bêta actuelle est conçue pour Windows 10 et Windows 11.

Retrio a-t-il besoin d’un compte ?

Non. La bêta s’installe et fonctionne sans créer de compte.

Retrouvez vos fichiers avec vos propres mots

Retrio analyse uniquement les dossiers que vous choisissez. Vos fichiers restent sur votre ordinateur.
