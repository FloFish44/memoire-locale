Comment retrouver un fichier Word ou Excel perdu ?

Retrouvez un document Word ou un tableau Excel grâce à son nom, son contenu, sa date et les dossiers récents de Microsoft Office.

Consulter les fichiers récents

Ouvrez Word ou Excel et regardez la liste Récent. Elle conserve souvent le chemin du dernier document ouvert, même si vous ne vous souvenez plus du dossier.

Rechercher une phrase ou une cellule

Notez un titre, un nom de client, une référence ou un texte distinctif présent dans le document. Ces indices sont plus fiables qu’un nom approximatif.

Vérifier les fichiers non enregistrés

Après une fermeture imprévue, les fonctions de récupération de Word ou Excel peuvent proposer une version temporaire. Enregistrez-la immédiatement dans un dossier clair.

Indexer les documents existants

Retrio peut extraire du texte de plusieurs formats bureautiques compatibles pour permettre une recherche avec les mots contenus dans le fichier.

Questions fréquentes

Retrio ouvre-t-il Word ou Excel ?

Retrio localise le fichier puis utilise l’application associée lorsque vous cliquez sur Ouvrir.

Les formules Excel sont-elles modifiées ?

Non. Retrio lit les informations utiles à la recherche sans modifier le classeur original.

Retrouvez vos fichiers avec vos propres mots

Retrio analyse uniquement les dossiers que vous choisissez. Vos fichiers restent sur votre ordinateur.
