How to find a lost folder in Windows

Simple ways to locate a folder that was moved, renamed or forgotten in Windows.

Search for a file inside it

If you remember one document from the folder, finding that document reveals the folder location.

Check Quick access

File Explorer may show the folder under Recent or Quick access.

Search from This PC

Use a distinctive part of the folder name and search across the likely drive.

Check parent folders

Review Documents, Desktop and recently changed folders.

Frequently asked questions

Can Retrio find an empty folder?

Retrio focuses on indexed files. Windows File Explorer is more suitable for finding an empty folder.

What if the folder was deleted?

Check the Recycle Bin and your backups first.

Find files using your own words

Retrio only analyses the folders you choose. Your files remain on your computer.
