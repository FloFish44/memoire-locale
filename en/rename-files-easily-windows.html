How to rename files easily in Windows

Rename one or several files clearly in Windows and use consistent names that remain easy to search.

Rename one file

Select the file, press F2, type the new name and press Enter.

Keep the extension

Do not remove .pdf, .docx or another extension unless Windows hides it automatically.

Use a consistent pattern

A subject, organization and ISO-style date make names easy to sort.

Be careful with bulk changes

Review a sample and keep a backup before renaming many files.

Frequently asked questions

Does Retrio currently rename files automatically?

No. Intelligent bulk renaming is planned for a future premium version.

Which characters should I avoid?

Windows does not allow characters such as < > : " / \ | ? * in filenames.

Find files using your own words

Retrio only analyses the folders you choose. Your files remain on your computer.
