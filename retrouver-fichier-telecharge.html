Où retrouver un fichier téléchargé ?

Vous avez téléchargé un fichier mais vous ne le trouvez plus ? Retrouvez-le dans Téléchargements, votre navigateur ou avec une recherche par contenu.

Ouvrir le dossier Téléchargements

Sous Windows, ouvrez l’Explorateur de fichiers puis choisissez Téléchargements dans la colonne de gauche. Triez les éléments par date de modification pour placer le téléchargement le plus récent en haut.

Consulter l’historique du navigateur

Dans Chrome, Edge ou Firefox, ouvrez la liste des téléchargements. Le navigateur affiche le nom reçu et propose généralement une action pour afficher le fichier dans son dossier.

Chercher avec ce que contient le fichier

Si le nom téléchargé est incompréhensible, décrivez son contenu. Retrio peut retrouver une facture ou un contrat avec un fournisseur, une date ou un montant présent dans le document.

Analyser seulement les bons emplacements

Dans Retrio, cochez Téléchargements et éventuellement Documents. Une zone courte accélère la première analyse et limite les résultats inutiles.

Questions fréquentes

Pourquoi mon téléchargement n’est-il pas dans Téléchargements ?

Le navigateur peut avoir mémorisé un autre dossier ou vous avoir demandé un emplacement lors de l’enregistrement.

Retrio peut-il retrouver un téléchargement renommé ?

Oui, lorsque son format et son contenu sont pris en charge, son nom exact n’est pas nécessaire.

Retrouvez vos fichiers avec vos propres mots

Retrio analyse uniquement les dossiers que vous choisissez. Vos fichiers restent sur votre ordinateur.
